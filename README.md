The apology a smart speaker gives its owner after it mishears them, written for
the [make.fun](https://make.fun/bounty/u-kiencx-sorry-i-heard-that-wrong-1858c729)
bounty **"Sorry, I Heard That Wrong"**.

> Sorry — I heard 'play jazz' as 'blame jazz', so I have spent the last hour accusing the saxophone.

`main.py` writes that single line (98 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`), pure Python standard library, no
third-party packages. It self-checks the gate before writing: UTF-8 text,
1 to 140 characters, a single non-blank line.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
